# 御魂匠（YYS Helper）

面向 Windows + MuMu 模拟器的本地《阴阳师》助手。普通模式使用 ADB 截图和 RapidOCR/MNN 读取画面，不读取游戏进程内存、不注入客户端；御魂数据、设置和审计日志只保存在本机。

## 当前能力

- 只读采集游戏中当前打开的御魂详情；不再依赖固定“御魂详情”标题，而是根据套装、等级和属性区域识别。
- 导入痒痒熊快照、新客户端御魂导出 JSON 或御魂匠标准 JSON，一次建立完整本地库存；导入前会预览并确认。
- 将真实御魂保存到本地 SQLite；每枚御魂使用独立本地 ID，相同属性的多枚御魂可以同时存在，强化后可用“更新选中”覆盖原记录。
- 对已有库存自动评分，并保护已装备、已锁定、低置信度、方案引用、六星速度胚及三有效词条御魂。
- 导入并校验 `|TA|...` 文字方案码，或从 PNG/JPG/WEBP 二维码图片中解码。
- 根据游戏已经计算出的方案详情读取套装、主属性和速度要求，再从本地库存求最优六件套；严格解不存在时显示最小缺口并推荐适合强化的胚子。
- 困 28 与御魂副本的受控状态机：每次动作前识别场景，达到次数/时长上限、体力不足、掉线、背包满或连续识别失败时停止；支持 `F12` 紧急停止。
- 每次详情读取和无法识别的日常场景都可保存本地诊断证据包，包含原始截图、OCR 文字、置信度和坐标。
- 独立演示模式，可在不连接 MuMu 时体验库存、配装和强化建议。

当前版本不会自动锁定、弃置或强化御魂。界面中的“强化建议”仅给出优先级和 `+3` 检查点，最终操作由你在游戏内确认。困 28 首版也不会自动更换满级狗粮。

## 安装与启动

需要 Windows 10/11、Python 3.11 或 3.12，以及已安装并启动的 MuMu 模拟器。

在 PowerShell 中进入项目目录并安装：

```powershell
.\scripts\setup.ps1
```

如果 `python` 不是 Python 3.11/3.12：

```powershell
.\scripts\setup.ps1 -Python "C:\Path\To\python.exe"
```

连接真实 MuMu：

```powershell
.\scripts\start.ps1
```

只看演示数据：

```powershell
.\scripts\start.ps1 -Demo
```

点击右上角“连接 MuMu”。程序会优先寻找 MuMu 自带的 `adb.exe`；若没有找到，选择 MuMu 安装目录中的 `adb.exe` 文件，而不是选择一个文件夹。

## 读取真实御魂

### 方法一：导入完整 JSON 库存（推荐已有快照时使用）

1. 进入“御魂仓库”，点击“导入库存 JSON”。
2. 选择痒痒熊快照、新客户端御魂导出文件，或 `yys-helper.inventory.v1` 格式文件。
3. 检查预览中的格式、有效数量、锁定/弃置数量和待复核数量。
4. 确认后，助手会用事务替换本地库存并立即重新计算配装与强化建议；这一过程不会连接或修改游戏。

助手只读取你已经拥有的 JSON 文件，不会下载、启动或内置需要账号凭证、进程注入或抓包的第三方导出器。导入采用全量严格校验：未知套装、坏记录或重复 ID 会阻止整次替换，原本地库存保持不变，不会静默生成残缺库存。当前映射覆盖普通御魂和首领御魂至 `300099`，首领御魂固有属性会合并进评分属性。

### 方法二：从当前详情页只读采集

1. 启动普通模式并连接 MuMu。
2. 由你在游戏里手动打开一枚御魂的详情页。
3. 进入“御魂仓库”，选择正确的位置和星级；套装名识别不稳定时可手动填写覆盖值。
4. 点击“新增读取”。这一步只截取当前画面并识别文字，不会点击游戏。
5. 御魂强化后，先选中原记录再点“更新选中”；误识别的记录可用“删除选中记录”从本地移除，这两个操作都不会改动游戏。
6. 逐枚采集后，方案配装和强化建议会立即基于本地真实库存刷新。

识别失败时不会写入数据库。OCR 置信度低于 `0.92` 的记录会进入保护范围，避免被当作可处理材料。失败日志会给出 `data/diagnostics/` 下的证据目录；其中 `screen.png` 是原始画面，`ocr.json` 是识别到的文字、置信度、坐标和错误阶段。

需要单独采集现场时，可点击“保存诊断采集”。它只执行截图与 OCR，不会点击游戏；“打开诊断目录”可直接查看保存的截图和识别结果。即使 OCR 引擎报错，只要截图已经成功取得，原始画面仍会保存。

## 使用他人的方案码

方案码本身是游戏的内部数据，助手无法可靠地离线还原其全部规则。推荐流程是：

1. 在“方案配装”粘贴文字码或选择二维码图片，点击“校验并复制”；程序会校验并复制方案码。
2. 在游戏的阵容/御魂助手中导入方案码并完成计算。
3. 手动打开游戏里的方案详情页。
4. 在助手填写目标式神的基础速度，再点击“读取当前游戏方案”。助手会把面板速度换算成御魂需要提供的数值，并展示识别摘要供确认。
5. 若没有完全满足的六件套，进入“强化建议”查看最值得培养的胚子。

当前版本只会自动换算面板速度阈值。暴击、攻击、生命、防御、效果命中/抵抗等面板阈值还涉及式神基础值和套装加成；识别到这些条件时助手会明确拒绝应用，避免给出“已满足”的错误结论。

## 日常任务与账号风险

自动化操作可能违反游戏服务条款并造成账号处罚。日常任务默认禁用，只有明确勾选风险确认后才能启动。程序不提供绕过检测、购买体力、充值或勾玉消费能力，也不承诺“防封”。

开始前请确认游戏处于前台和可识别入口，并先使用很小的循环次数验证。任何时候按 `F12` 都会阻止后续新点击。未知场景下程序会停止，不会猜坐标继续操作。

自动任务运行时，连接、御魂采集和方案读取按钮会被锁定，避免只读 OCR 与战斗状态机互相干扰。

## 本地数据

- 御魂、设置和操作审计：`data/yys-helper.db`
- OCR/未知场景诊断包：`data/diagnostics/<时间>-<用途>/`
- 其他临时截图和日志：`data/`、`logs/`
- 这些目录默认不会提交到 Git，也不会自动上传到云端。
- 普通模式绝不回退到模拟库存；只有 `-Demo` 参数会显示样例数据。
