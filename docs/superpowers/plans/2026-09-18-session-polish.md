# 图标、挂机节奏与任务体验

目标：新的 Apple 风格图标，统一受控的随机节奏与严格会话上限，减少任务配置和停止时的歧义。

沿用用户已授权的当前目录开发、无需追问、离线测试、完成后提交 GitHub；不连接或操作游戏账号。

## 设计决策

- 使用 imagegen 内置工具生成白色圆角底座、冰蓝阴阳符号图标，替换应用 PNG、打包 ICO 和既有桌面快捷方式图标；不更改快捷方式启动参数。
- 自动操作的随机性只影响有界等待和识别框中心附近的落点。保留场景确认、唯一目标、取消和截止时间检查；不生成无关点击、注入或规避检测功能。不能承诺防封。
- 默认单次 45 分钟，界面和领域模型均限制最多 120 分钟，包含 OCR、等待和休息；到时不开始新动作，也不自动续跑。这不是防封安全阈值。
- 标准/舒缓节奏；随机间隔、随机轮次后的短休息，休息只能在战斗结束的边界发生。长等待后重新识别，不能拿旧坐标继续点击。
- 任务中心明确连接、配置和风险确认状态；支持立即停止及本轮后停止；显示剩余时长、休息倒计时、最后停止原因。高级识别配置折叠，活动标题保留在外层。
- 整理页补充搜索/保护状态筛选与空结果反馈；改进小窗口布局、主操作层级和键盘可访问性。

## 实施顺序

1. tests/test_pacing.py 先覆盖随机区间、框内落点、休息边界、取消、截止时间、NaN/超限配置，运行失败测试；实现 automation/pacing.py 与 engine.py/runtime.py 集成，再验证。
2. tests/test_task_center.py 与 test_ui_smoke.py 先覆盖连接门禁、无效配置禁用、上限持久化、本轮后停止、搜索筛选；实现界面与 TaskWorker，回归既有测试。
3. 集成生成图标与 ICO；用 scripts/render_ui.py 离屏检查五页和小窗口；更新已有桌面快捷方式并读回校验。
4. 全量 unittest、compileall、pip check、wheel、git diff --check；独立代码复核后提交并推送。不把离线测试称为实机验证。

## 验证记录

- 图标生成与打包完成；Windows ICO 含 16/24/32/48/64/128/256 像素版本。已更新并读回桌面快捷方式，原 pythonw.exe 目标、启动参数和工作目录保持不变。
- 145 项 unittest 通过；包括随机区间/点击框、截止时间截断、长休息、复合动作二次取消、等待/刷新期间的本轮后停止、旧 worker 身份过滤、真实 QThread 通知 GUI 线程、库存筛选和旧超长配置收紧。
- compileall、pip check 通过。五个页面及 1050×680 小窗口离屏渲染检查完成；控制区缩小，配置区可滚动；本地截图在 data/ui-previews，不上传。
- 独立只读复核提出的两处 Important（延迟中的本轮后停止、旧线程通知解锁新任务）均先复现后修复，复查通过。
- 未连接模拟器，未进行真人游戏实测；随机节奏不能验证或保证反检测效果。
